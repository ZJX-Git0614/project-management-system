## 1. 业务背景

佳哥的工作场景以"项目进度管理"为核心——多个项目并行，每周/每月需要追踪关键事项、识别风险、安排活动、对接干系人。RPMS 系统专注于"维修备件生命周期管理"（必换件/选换件/结构件/采购/测试/技术指标），是"项目执行细节"的下沉工具；本系统则上移到"项目经营驾驶舱"层面，关注的是项目全局状态与跨项目的关键事项追踪。

**目标用户：** 项目经理 / 项目成员 / 系统管理员
**核心场景：** 快速看到"我手头几个项目分别什么状态、本月/本周要交付什么、谁还没交付"。

## 2. 范围边界

### 包含
- 项目基础信息管理（编号、甲方、合同金额、设备数量、维修周期、起止日期、状态机）
- 项目组成员管理（按角色从人员库选人）
- 项目生命周期状态机（草稿 → 进行中 → 已完成/已作废，COMPLETED/VOIDED 只读）
- 三个全局视图：**项目进度总揽 / 本月事项 / 本周事项**
- 后台账号管理 / 角色与人员库配置 / 权限树管理
- 简易待办中心（复用 RPMS 的 TodoItem 模型，用于项目级推送；第一阶段保留为占位）

### 不包含（v0.1）
- 必换件 / 选换件 / 结构件 / 采购 / 测试 / 技术指标 — 全部下沉到 RPMS
- 维修周期 / 设备生命周期管理 — 由 RPMS 负责
- 财务结算 / 收款 / 发票 — 后续版本
- 文件存储 / 富文本 — 后续版本
- 通知 / 邮件 — 后续版本
- 多语言 — 仅中文

   - 后台账号管理（/admin/accounts）

## 4. 数据模型

### Project
| 字段 | 类型 | 说明 |
|------|------|------|
| id | string (cuid) | 主键 |
| name | string | 项目名称（必填）|
| code | string | 项目编号（可选）|
| clientName | string | 甲方单位（可选）|
| amountWan | float | 合同金额（万元）|
| deviceCount | int | 设备数量 |
| repairCycleDays | int | 维修周期（天）|
| startDate | string | 开始日期 YYYY-MM-DD |
| expectedEndDate | string | 预计结项日期 YYYY-MM-DD |
| status | enum (DRAFT/IN_PROGRESS/COMPLETED/VOIDED) | 生命周期状态 |

### ProjectMember
- projectId, roleName（来自 RoleConfig.roleName）, personName

### MonthlyItem / WeeklyItem
- projectId, title, description, dueDate, status(PENDING/IN_PROGRESS/DONE/CANCELED), owner, priority(LOW/NORMAL/HIGH/URGENT)

### RoleConfig
- roleName, allowMultiple, systemPreset, persons(JSON array of personName)

### UserAccount
- username, displayName, enabled, assignedRoleNames(JSON array), passwordHash, passwordResetRequired

### SystemPerson
- personName（项目成员库，由 UserAccount 自动同步）

### TodoItem
- 保留，第一阶段作为占位；与 RPMS 行为一致

### OperationHistory
- projectId, entityType, entityId, actionType, operator, detail

### PermissionTree
- id="default_tree", data(JSON: 全局权限树)

## 5. 权限模型

权限树由 `src/lib/permissions.ts` 中 `buildDefaultPermissionTree()` 初始化，覆盖以下 7 组：

```
├─ 项目经营驾驶舱 (project-list:view, project-detail:view)
├─ 项目进度追踪 (overview:view, monthly-items:view/..., weekly-items:view/...)
├─ 项目信息管理 (project-info:view/edit/start/complete/void/restore)
├─ 项目成员 (project-members:view/create/delete)
├─ 角色与人员 (role-config:view/edit/create/delete)
├─ 账号管理 (account-management:view/create/edit/delete/password)
└─ 权限树 (permission-tree:view/edit)
```

默认权限（管理员）：
- 系统管理员自动拥有所有权限
- 项目经理：项目进度追踪、项目信息管理、项目成员、角色与人员（只读）
- 项目成员：项目进度追踪（只读）、项目成员（只读）

## 6. 业务流程

### 项目状态机
- 草稿（DRAFT）→ 启动 → 进行中（IN_PROGRESS）
- 进行中 → 完成 → 已完成（COMPLETED）— 只读
- 进行中 → 作废 → 已作废（VOIDED）— 只读
- 已完成/已作废 → 恢复 → 进行中（IN_PROGRESS）

### 事项状态机
- 待开始（PENDING）→ 进行中（IN_PROGRESS）→ 已完成（DONE）
- 任意状态 → 已取消（CANCELED）

### 项目成员管理
- 创建/编辑项目时从 `RoleConfig` 中选人
- 人员库（SystemPerson）由 UserAccount 自动同步（仅项目成员/项目经理角色）
- 编辑/删除账号时校验"该人员是否在项目成员中"——若在，阻止并提示
