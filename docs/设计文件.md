## 2. 关键设计

### 2.1 状态机（只读守卫）
COMPLETED / VOIDED 状态下的项目，所有写操作（PUT/POST/DELETE）通过 `ensureMutableProject(projectId)` 统一拦截。
唯一例外：恢复操作（VOIDED/COMPLETED → IN_PROGRESS）通过 `isStatusTransitionAllowed()` 放行。

### 2.2 人员同步
账号创建/编辑/删除时自动同步 `SystemPerson` 表：
- 仅"项目成员"或"项目经理"角色的人员进入 `SystemPerson`
- `RoleConfig.persons` 同时按角色更新

### 2.3 跨项目聚合
`/api/overview` / `/api/monthly-items` / `/api/weekly-items` 是跨项目全局视图：
- 后端不做项目范围过滤
- 前端按"项目"列 + 顶部"项目筛选"实现用户侧过滤
- 视图状态（PENDING/IN_PROGRESS/DONE/CANCELED）按 `dueDate` 落在时间窗口内计算

### 2.4 权限树
- 启动时调用 `buildDefaultPermissionTree()` 初始化
- 通过 `/admin/permission-tree` 页管理（可勾选/不勾选）
- 实际生效由后端按 roleName 查 `RoleConfig` → 关联权限键 → 与 `PermissionTree.data` 求交集

## 4. 数据流

### 4.1 创建项目
```
CreateProjectDialog
  → POST /api/projects (body: name/code/clientName/...)
  → 写入 Project 表
  → 返回新项目 ID
  → 切换导航至 /projects/[id]?nav=project
```

### 4.2 新增本月事项
```
ItemPanel (kind=monthly)
  → ItemDialog submit
  → POST /api/monthly-items (body: projectId/title/dueDate/owner/...)
  → 校验项目状态 (非 COMPLETED/VOIDED)
  → 写入 MonthlyItem
  → 写入 OperationHistory
  → 刷新 ItemPanel
```

### 4.3 启动 / 完成 / 作废项目
```
ProjectInfoTab.handleStatusAction(action)
  → PUT /api/projects/[id] (body: status)
  → 校验旧状态：
     - start: DRAFT → IN_PROGRESS
     - complete: IN_PROGRESS → COMPLETED
     - void: IN_PROGRESS → VOIDED
     - restore: COMPLETED/VOIDED → IN_PROGRESS (放行)
  → 写 OperationHistory
```

### 4.4 登录
```
LoginForm submit
  → POST /api/auth/login (body: username, password)
  → 校验 user.enabled + verifyPassword
  → signToken({userId, username, displayName})
  → 写入 localStorage
  → router.push("/projects")
```

## 5. UI 组件层级

```
<AppShell>
  ├─ <TopBar>（用户/项目切换/待办中心）
  └─ <Sidebar>（3 个一级分组）
        ├─ 项目经营驾驶舱
        ├─ 项目进度追踪
        └─ 系统设置

<ProjectListPage>
  ├─ <CreateProjectDialog>
  └─ <Table> (项目列表)

<ProjectDetailPage>
  ├─ 头部（项目名/编号/客户/状态 Badge）
  └─ <ProjectInfoTab>
        ├─ 项目基础信息 Card（编辑/状态切换）
        └─ 项目组成员 Card（添加/移除）

<ItemPanel> (kind=monthly | weekly)  ⭐ 共享组件
  ├─ 筛选区（关键词/项目/状态 + 导出 + 新增）
  ├─ <Table> (事项列表)
  └─ <ItemDialog> (新增/编辑)

<OverviewPage>
  ├─ 项目分布 Card（4 个统计）
  └─ 月度/周度事项完成率双卡片
```

## 6. 部署

- 开发：`npm run dev` 或 `npm run dev:local` (PORT=3002)
- 生产：`npm run build && npm run start` (3000) 或 `npm run start:local` (3002)
- 镜像：prisma db push + db seed + build
