Ceastar项目管理系统 2026.08.04.3 数据库迁移说明
================================================

一、迁移原则

1. 保留目标电脑 PostgreSQL 数据卷中的全部业务数据。
2. 不携带、不导入开发电脑的数据库备份。
3. 更新前自动备份目标数据库和项目文档。
4. 仅执行幂等的增量结构迁移和必要的数据兼容修复。
5. 任一迁移失败时停止应用启动，避免系统在结构不完整的数据库上继续运行。

二、本次累积升级补齐的主要内容

1. 甘特任务关键路径计算字段：最早开始、最早完成、最迟开始、最迟完成、总浮动、自由浮动、排程状态和计算时间。
2. 甘特任务描述默认值统一为“无”，仅修复原本为空的任务描述，不改写已有描述。
3. 恢复相关表 updatedAt 字段与 Prisma 模型的一致性，解决数据库恢复和后续迁移兼容问题。
4. 继续执行此前版本中尚未落库的依赖关系、工期、负责人、日历、删除撤销和助手配置等幂等迁移。
5. 新增 ProjectModuleHistorySnapshot 表、外键和组合索引，用于项目事项、风险登记册和预算管理按项目、模块和浏览器会话保存撤销/重做快照。
6. 新增 WeeklyItemGanttTask 表，把项目事项与 WBS 任务扩展为多对多关联；迁移会把旧 ganttTaskId 标量关系自动回填到新表。
7. 新增 RiskRegisterItemWeeklyItem 表，把风险与项目事项扩展为多对多关联；风险不再直接关联 WBS，受影响任务由关联事项的 WBS 任务集合自动推导。
8. 修复账号、角色、项目成员和权限树引用：仅清理确实不存在的角色引用；损坏的 JSON 原值会保留并跳过，不会被自动覆盖为空。
9. 新增表和兼容字段属于 Expand 兼容迁移：旧版本应用不依赖新关联表，绿色候选验证期间旧应用可以继续运行。
10. 修复旧版 WBS 负责人数据：父任务负责人仅回填尚未分配的后代，最近父级优先，然后重新计算父级负责人汇总。
11. 对项目成员建立“项目 + 账号”唯一索引；迁移前会合并旧重复成员并重指向对应的 WBS 负责人。
12. 新增 ProjectRestoreBatch，记录项目级恢复的预检、执行、30 天保护快照和回滚状态。
13. 新增 SystemEventLog 及时间、级别、类别、模块、项目和操作人索引，用于 180 天系统事件日志查询与导出。

三、不会被覆盖的内容

1. 项目、项目成员、甘特任务、事项、风险和预算业务数据。
2. 用户账号、角色、权限和智能助手供应商配置。
3. 项目上传文档、系统备份和 Ollama 模型。

四、失败恢复

1. 更新前备份位于原部署目录的 backups\时间戳 文件夹。
2. 绿色候选验证或正式切换失败时，update.ps1 会自动恢复更新前应用镜像；更新成功后仍可运行 rollback.bat 主动回退。
3. rollback.bat 不会删除新增字段，也不会覆盖更新后写入的数据。
4. 应用回退不反向删除 ProjectModuleHistorySnapshot、WeeklyItemGanttTask、RiskRegisterItemWeeklyItem、ProjectRestoreBatch、SystemEventLog 等新增结构；只有在确认业务数据损坏时，才使用系统数据管理中的数据库恢复功能选择更新前备份。
