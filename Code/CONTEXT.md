# 项目管理系统

本上下文定义项目计划、任务层级及相关业务操作中的统一语言，避免界面、接口和使用说明对同一概念产生不同解释。

## Language

**任务结构操作**：
改变甘特任务集合、层级或排列关系的操作，包括新增、删除、恢复、层级调整、拖拽排序、剪切和粘贴。
_Avoid_: 任务编辑、普通修改

**任务字段编辑**：
只改变单个任务业务字段且不改变任务集合、层级或排列关系的操作。
_Avoid_: 结构调整

**排期导入**：
将上传排期中可匹配的任务字段、层级和依赖关系批量写入当前项目 WBS 的任务操作。
_Avoid_: 排期文件转换、导出可导入文件

**排期导入预览**：
在执行排期导入前展示拟新增、更新、保留、冲突和依赖变化的完整结果。
_Avoid_: 导入结果、文件解析结果

**疑似任务匹配**：
上传排期中没有稳定任务标识、但名称或其他业务字段与当前 WBS 任务相似的待用户决定关系。
_Avoid_: 已匹配任务、同名任务

**资源冲突**：
同一负责人承担的可执行任务在时间上发生重叠，或固定日期任务无法满足负责人串行执行约束的排程异常。
_Avoid_: 紧前任务冲突、人员重复

**负责人并行**：
负责人集合没有交集的独立叶子任务允许在相同时间段并行执行；资源约束只由同一具体人员的可用工时和任务占用产生。
_Avoid_: 按项目全局串行、按角色名称串行

**个人不可用时间**：
人员请假、培训、会议、半天不可用等个人日历例外；当前排期模型不记录或计算该类时间，仅使用项目工作日历和法定节假日。
_Avoid_: 项目工作日历、固定日期任务

**自动排程任务**：
仅已录入工期、优先级、负责人和可用排期锚点、但尚未由用户固定计划日期的任务；计划开始和计划完成可为空，并由系统在父级边界、FS 紧前关系和负责人资源约束内计算。
_Avoid_: 自动导入任务

**固定日期任务**：
计划日期由用户或导入文件明确锁定，系统发现排程矛盾时必须展示冲突、受影响范围和可执行调整方案；未经用户明确选择“应用方案”，不得移动计划日期。
_Avoid_: 手动创建任务

**里程碑标记**：
用户为任意层级 WBS 任务设置的项目管理标识，仅用于强调关键节点，不改变该任务的业务属性或排程结果。
_Avoid_: 零工期任务、里程碑任务类型

**预计结项时间**：
用户在项目信息中维护的项目目标完成日期，不由 WBS 排程自动生成或覆盖。
_Avoid_: WBS 最晚完成时间、自动计算结项时间

**WBS 字段筛选**：
按任务字段过滤当前 WBS 可见行、同时保留命中任务父级路径的只读视图操作。
_Avoid_: 任务搜索、任务排序、修改任务层级

**透明数据表格**：
系统中以行列数据为主体的业务和管理表格所采用的统一交互样式：单元格只读时透明，编辑时才显示输入控件边界。
_Avoid_: 全局透明主题、无边界输入框

**Windows 智能服务管理**：
Windows 部署包中负责本机 Ollama 和 RAGLite 启停、状态检查、异常恢复及开机自启配置的本地运维工具。
_Avoid_: 智能助手网页启停服务、手动 PowerShell 运维

**RAGLite 本地运行环境**：
Windows 完整部署包可选安装并由 Windows 智能服务管理接管的锁定版本 RAGLite 服务及离线依赖。
_Avoid_: PMS 应用内嵌检索代码、每次热更新重复安装 RAGLite

**结构化排期文件**：
通过确定性解析保留任务字段、层级和依赖的 MPP、Microsoft Project XML、XLS、XLSX 或 CSV 文件。
_Avoid_: 普通项目文档

**半结构化排期文档**：
由智能助手从 DOCX、PDF、MD 或 TXT 中提取任务信息并为不确定字段标记可信度的排期来源。
_Avoid_: 结构化排期文件、扫描件

**排期字段映射**：
将上传排期的工作表、表头、字段、层级表达和依赖引用对应到 WBS 数据结构的导入配置。
_Avoid_: 助手自由猜测、数据库字段映射

**资源冲突提示**：
在 WBS 中持续展示负责人任务重叠的任务级、父级汇总及项目级入口，不自动替用户修改固定日期或负责人。
_Avoid_: 自动冲突解决、一次性导入警告

**资源排期建议**：
系统针对已识别资源冲突或不可行排程计算的一个或多个可解释调整方案，只能在移动未开始自动任务、调整父级边界、修改固定任务方式或日期、重新分配负责人四类范围内供用户预览和选择；方案可显式包含范围外受影响自动任务，且在权限允许时作为一次可撤销的原子变更应用。
_Avoid_: 自动资源平衡、强制改期

**自动排期预览门槛**：
自动排期未造成冲突、固定任务影响、关键路径变化或父级硬边界变化时可直接应用并支持撤销；出现任一情况时必须先展示前后对比与方案，批量覆盖子任务排期方式始终必须预览，用户仅可应用方案或强制保存为不可发布基线的冲突草案。
_Avoid_: 无条件自动保存、跳过影响预览

**资源平滑**：
在不改变项目最晚完成日期的前提下，优先利用任务浮动消除或降低负责人资源冲突的排程优化方式。
_Avoid_: 资源平衡、自动延期

**资源平衡**：
为消除负责人资源冲突允许移动任务并可能延长项目最晚完成日期的排程优化方式，必须由用户预览并确认后应用。
_Avoid_: 资源平滑、自动保存

**排程优先级**：
在同一负责人资源、日期窗口和其他硬约束发生竞争时，决定自动排程让位顺序的任务字段，默认值为普通。
_Avoid_: 项目事项优先级、任务显示排序

**自动排期竞争顺序**：
同一负责人下可开始的自动任务先满足 FS 紧前关系，再按生效优先级从高到低、较早的固定完成或父级完成边界、原 WBS 行顺序排期；负责人集合无交集的任务允许并行。
_Avoid_: 倒排优先、按任务 ID 排期

**无依赖自动任务**：
已录入工期但没有紧前任务、且处于自动排程模式的叶子任务；系统必须依据父级日期边界、项目目标和排程优先级计算其计划日期及最早/最晚时间字段。
_Avoid_: 未排期任务、固定日期任务

**负责人日容量**：
一个可执行任务负责人在一个工作日内可投入的预计工时上限，当前固定为 7.5 小时；半天任务按 3.75 小时占用。
_Avoid_: 任务工期、项目总工时

**排程资源范围**：
当前自动排程与资源冲突计算实际使用的资源类型；本期仅纳入项目成员，设备、工装、场地和供应商仅保留后续扩展能力。
_Avoid_: 项目预算分类、文档关联目录

**关键路径**：
仅依据任务依赖、日期边界和工期计算出的最长逻辑链路；其任务延误会直接影响项目最晚完成日期。
_Avoid_: 资源冲突链、任务优先级

**资源关键链**：
在关键路径计算基础上纳入负责人日容量、资源平滑或资源平衡所产生等待时间的最长可交付链路。
_Avoid_: 紧前任务、负责人汇总

**排程模式**：
决定任务计划日期可由系统重算还是必须由用户保持的任务字段。固定日期任务可以获得调整建议，但只有用户明确应用建议后才允许改动日期。
_Avoid_: 任务状态、导入模式

**任务计划计算方式**：
任务计划字段的输入与推导关系，取值为工期固定-正排、工期固定-倒排或日期固定；正排以计划开始和工期推导计划完成，倒排以计划完成和工期推导计划开始，日期固定以计划开始和计划完成推导工期。
_Avoid_: 自动排程、基线冻结

**排期方式字段编辑权**：
自动排期和父任务自动汇总状态下的计划日期只读；工期固定正排仅可编辑计划开始与工期，工期固定倒排仅可编辑计划完成与工期，日期固定仅可编辑计划开始与计划完成。
_Avoid_: 禁用但可提交的日期控件、任意日期编辑

**任务排期状态**：
任务在自动排程任务、工期固定-正排、工期固定-倒排和日期固定四种状态之一。只有自动排程任务可由系统直接移动日期；后三种状态均为用户提供的硬约束，系统只能计算影响并提出调整方案。
_Avoid_: 任务状态、基线状态

**用户优先级**：
非关键、无依赖的最末级可执行任务由用户设置的低、中或高优先级。该值在任务临时进入关键路径或依赖约束状态时必须保留，以便状态解除后恢复。
_Avoid_: 生效优先级、任务紧急程度文本

**生效优先级**：
排期算法实际使用的派生优先级。关键路径任务固定为最高，有紧前或紧后依赖但非关键路径的最末级任务固定为高；其余任务使用用户优先级。父任务仅汇总展示后代最高生效优先级，不参与资源抢占。
_Avoid_: 用户优先级、父任务资源优先级

**任务暂停**：
任务执行过程中的临时中断状态；当前排期模型不记录暂停窗口、恢复日期或剩余工时重排，暂停处理留待后续独立迭代。
_Avoid_: 自动排程中的日期锁定、已完成任务

**排期导入工作区**：
由助手聊天中的导入摘要进入、用于完整核对排期字段映射、匹配、冲突、层级和依赖并最终确认写入的树形预览界面。
_Avoid_: 聊天消息表格、导入结果页

**任务插入**：
以当前选中任务为位置参照，一次新增一个或多个同级任务或子任务的结构操作。
_Avoid_: 新建弹窗、追加任务

**任务层级调整**：
在保持任务可见行顺序不变的前提下，改变所选任务分支的父子关系并重新生成受影响任务 ID。
_Avoid_: 任务排序、拖拽换行

**显式选择**：
用户直接通过序号列选中的任务。
_Avoid_: 自动选择、分支选择

**表格行选择**：
用户通过序号列直接选中的项目事项或风险条目集合。
_Avoid_: 复选框模式、右键选择命令

**联动选择**：
因显式选择父任务而自动包含且不可单独取消的后代任务。
_Avoid_: 多选、显式选择

**任务剪贴板**：
保存当前项目内待复制或待移动任务范围及其相对关系的临时业务状态。
_Avoid_: 系统剪贴板、跨项目任务

**任务序号**：
任务在完整任务树当前行顺序中的连续位置编号。
_Avoid_: 任务 ID、数据库主键

**任务操作历史**：
当前浏览器标签页内按时间顺序保存的最近五十步任务结构操作、已保存字段编辑及其撤销状态。
_Avoid_: 操作日志、未保存输入

**模块操作历史**：
按项目与业务模块独立保存已完成增删改及排序操作的可撤销记录。
_Avoid_: 全项目共享历史、操作日志

**撤销**：
将当前模块数据恢复到最近一次已执行业务操作之前的状态。
_Avoid_: 恢复备份、撤销其他模块

**重做**：
在已执行撤销后，重新应用最近一次被撤销的业务操作。
_Avoid_: 反撤销、取消撤销

**删除影响**：
删除业务对象后将自动变为不关联状态的其他项目数据及其原关联。
_Avoid_: 级联删除、删除对象本身

**项目级恢复**：
以一个完整项目及其全部项目内业务数据和关联为最小单位的局部数据库恢复。
_Avoid_: 单表恢复、部分项目数据覆盖

**关联账号恢复**：
项目级恢复中，由管理员主动选择从备份一并恢复当前系统已不存在的历史成员账号。
_Avoid_: 自动创建账号、按姓名自动匹配

**恢复会话延续**：
完整数据库恢复后，在当前操作管理员的同一账号仍有效且仍具管理权限时继续当前登录状态。
_Avoid_: 无条件保留登录、恢复后强制退出

**父级负责人汇总**：
父任务根据其后代任务的负责人自动得出的只读负责人集合。
_Avoid_: 父任务独立负责人、手工汇总

**可执行任务负责人**：
最末级叶子任务可直接分配的一名项目成员；一个叶子任务不得同时存在多名直接负责人。
_Avoid_: 父级负责人汇总、多人协同资源分配

**自动排期负责人前置条件**：
自动排期范围内的普通末级任务必须恰有一名直接负责人，未分配时阻止排期；零工期里程碑可无负责人且不占用资源。
_Avoid_: 未分配任务自动占用资源、父级负责人手工分配

**父级日期边界**：
父任务由用户手动填写的计划开始和计划完成日期构成后代任务的排程窗口；仅修改父任务边界时不得改动后代日期或工期，越界须显示影响与方案，父任务采用正排、倒排或日期固定时默认锁定该边界，只有用户主动降级为计划目标边界时才允许作为提醒型目标处理。未手动设置边界的父任务日期只由后代任务的最早开始和最晚完成自动汇总。
_Avoid_: 父任务自动延期、叶子任务固定日期

**最后一级父任务自动排期范围**：
最后一级仍包含子任务的父任务发起自动排期时，系统默认且仅处理其全部后代任务，不再要求用户选择影响范围。
_Avoid_: 手工多选范围、全项目优化排期

**自动排期影响范围**：
较高层父任务发起自动排期时，用户只能从其后代中多选最后一级父任务，每个已选父任务代表其完整后代任务集合，不允许挑选半棵子树或单独叶子任务；范围外关联任务默认作为固定约束，但可由用户确认应用的候选方案显式纳入变更集。
_Avoid_: 任意任务多选、跨父级零散排期

**自动排期入口**：
自动排期仅在父任务右击菜单的一级操作中提供；最后一级父任务直接处理全部后代，较高层父任务通过独立范围面板选择后代最后一级父任务，叶子任务不提供该操作。
_Avoid_: 叶子任务自动排期入口、级联菜单范围选择

**子任务排期方式覆盖**：
父任务排期设置可选择将自动排期、工期固定正排或工期固定倒排覆盖给未开始子任务，但不得覆盖已开始或已完成任务的工期、日期和负责人，且日期固定不得批量覆盖。
_Avoid_: 批量改写任务字段、批量日期固定

**硬边界冲突**：
任务的固定日期、固定工期、依赖关系或资源约束使其无法落在父级硬边界内的阻断性排期状态。系统必须持续展示强提醒、受影响范围和可执行调整方案；任一相关字段变化后必须重新计算方案。冲突可暂存于未发布的排期草稿，但未解决前禁止发布或变更发布基线。
_Avoid_: 一般资源冲突、允许确认的排期警告

**排期硬冲突**：
阻断正式基线发布、但可暂存于未发布草稿的排期逻辑冲突，包括硬边界冲突和不满足已定义紧前关系的时序冲突。系统必须持续展示影响与解决方案，直至冲突消除。
_Avoid_: 数据完整性错误、业务风险警告

**业务风险警告**：
不破坏当前项目排期数据完整性、但可能增加交付风险的可确认警告，例如跨项目资源冲突、超过项目目标完成时间或关键路径变化；项目经理可以填写确认原因后带风险发布基线。
_Avoid_: 排期硬冲突、阻断错误

**项目内资源冲突**：
同一负责人在当前项目中被安排到重叠的可执行叶子任务所形成的排期硬冲突；可强制暂存但未消除前不得发布或变更发布基线。
_Avoid_: 跨项目资源冲突、一般业务风险警告

**跨项目资源冲突**：
同一负责人被当前项目与其他进行中项目同时占用的交付风险；当前项目仅展示强提醒与影响说明，不以此阻断本项目的基线发布。
_Avoid_: 项目内资源冲突、跨项目自动改期

**连续任务排期**：
本期自动排期只为一项未完成叶子任务分配连续的时间段，不将同一任务拆分为多个不连续片段。工期最小粒度为 0.5 天；任务穿插、抢占和暂停后的剩余工时重排不在本期范围。
_Avoid_: 任务暂停、可拆分任务

**FS 紧前关系**：
本期唯一支持的任务依赖关系。紧后任务必须从紧前任务计划完成或实际完成后的下一个可用半日时段开始，并可设置 0.5 天粒度的非负间隔。SS、FF、SF 和负间隔不在本期排期范围。
_Avoid_: 任务类型、软提示依赖

**半日排期时段**：
排期引擎将每个可工作日期划分为两个连续时段，每段为 3.75 小时。界面使用上箭头 `↑` 表示上半日、下箭头 `↓` 表示下半日；任务可在同一日期的相邻时段顺序衔接，无需虚构具体钟点。
_Avoid_: 实际钟点考勤、任务拆分

**预计工时公式**：
最末级可执行任务的预计工时为工期乘以 7.5 小时的只读派生值。工期为空时预计工时显示 `--`，不得写入 0 或虚构数值；实际工时由用户手工填写，可保留两位小数。
_Avoid_: 预计工时手工覆盖、投入比例

**项目日历模式**：
项目级统一排期日历，取值为自然日或工作日。自然日连续计算所有日期；工作日按中国法定节假日和调休工作日计算。项目内任务不得单独覆盖该模式。
_Avoid_: 单任务日历例外、个人不可用时间

**项目日历例外**：
由有权限管理员维护、作用于整个项目的公司统一放假日或调休工作日。例外与年度中国工作日历共同组成项目使用的版本化日历；不支持个人或单任务例外。
_Avoid_: 人员请假、临时任务暂停

**项目硬完成边界**：
项目经理可选启用的根层级不可逾越完成日期，适用于合同交付等强约束。它不同于预计结项时间；无法满足时形成排期硬冲突并阻止发布基线。
_Avoid_: 预计结项时间、自动延期项目目标

**受影响排期集合**：
一次任务字段变化默认纳入自动排期的最小闭包：当前任务、所有受影响的未完成紧后任务、与其共享负责人且可能发生资源竞争的当前项目未完成任务，以及这些任务继续引起的紧后依赖链。父任务仅用于边界校验和日期汇总；其他项目任务只视为已占用资源，不得被自动移动。
_Avoid_: 全项目优化、仅当前行重算

**自动排期锚点**：
自动排程任务寻找日期的优先来源：父级完整硬边界、父级单侧开始或完成边界、项目预计结项时间、项目开始日期。没有任何可用边界时任务保持未排期并提示补充信息；父任务由子任务自动汇总出的日期不是新的硬边界。
_Avoid_: 自动补全假日期、父任务滚动边界

**已发布基线冻结**：
项目 WBS 基线发布后的计划锁定状态。仅允许填写实际开始、实际完成、实际工时和当前进度；任务结构、任务名称、描述、类别、负责人、优先级、计划日期、工期、依赖关系和备注均不可直接修改，必须通过基线变更草案处理。
_Avoid_: 项目只读、已完成任务

**完成任务状态**：
任务当前进度达到 100% 或填写实际完成日期后进入完成状态。实际开始和实际完成均只能是当前日期或过去日期，并使用半日时段精度；两者互相同步：填写实际完成日期自动将进度设为 100%，将进度改为 100% 自动填写当前日期下半日。完成任务不再占用负责人资源，也不再作为未完成任务的活动排期约束。
_Avoid_: 计划完成、任务暂停、进度预测

**完成任务重开**：
完成任务默认只读。只有当前项目经理通过基线变更重新发布后，才能将进度改回 100% 以下；重开时必须清除实际完成日期，并重新进入未完成任务的排期和资源检测。
_Avoid_: 普通编辑、撤销实际填报

**父任务汇总完成**：
具有子任务的父任务是汇总节点，进度、完成状态和实际完成日期由子任务计算，不直接占用负责人资源。任一子任务未完成时父任务不得完成；全部子任务完成后父任务自动为 100%，实际完成日期取最后一个子任务的实际完成日期。
_Avoid_: 父任务手工完成、子任务完成数量

**父任务进度权重**：
父任务汇总进度优先使用子任务预计工时作为权重；缺少预计工时时仅在计算中使用工期乘以 7.5 小时的临时权重，不写回任务字段。所有子任务都没有工时和工期时按数量等权；只有部分子任务缺少权重时显示 `--` 并列出缺失项，不生成误导性的百分比。
_Avoid_: 自动填充预计工时、简单平均进度

**基线变更草案权限**：
独立于项目 WBS 编辑权限的角色权限，用于创建和编辑未发布的基线变更草案。是否授予由权限树单独配置；无论草案由谁准备，只有当前项目经理可以发布基线或应用基线变更。
_Avoid_: 基线发布权限、普通 WBS 编辑权限

**WBS 基线版本**：
项目 WBS 在一次正式发布时生成的完整、不可变快照，包含任务结构、计划字段、负责人、依赖关系、优先级、关键路径和排期计算结果。首次发布为 V1，后续每次变更发布均生成递增的新版本，不得覆盖历史版本。
_Avoid_: 当前草稿、可编辑的任务备份

**基线回退**：
以某个历史 WBS 基线版本为来源生成新的基线变更草案、经影响预览和项目经理确认后发布为新版本的操作。回退不得删除、修改或伪造任何已有版本。
_Avoid_: 直接覆盖当前基线、数据库恢复

**单一活动基线草案**：
同一项目在任一时刻最多存在一份未发布的基线变更草案。草案创建者可编辑，项目经理可查看、接管或作废；其他拥有草案权限的成员可查看但不得并行创建第二份草案。
_Avoid_: 多人实时协同编辑、多个并行基线分支

**基线发布通知**：
首次发布、变更发布和基线回退发布后，系统向全部项目成员创建持久通知，包含版本号、变更原因、关键影响摘要和前后对比入口。在线成员只收到 2 秒横幅提示；通知可记录已读时间，但不以成员确认作为基线生效前提。
_Avoid_: 待办阻塞、长期悬浮横幅

**任务依赖类型**：
任务之间的时间关系。本期仅支持完成-开始（FS）；未标注依赖按 FS 处理。历史或导入的开始-开始（SS）、完成-完成（FF）、开始-完成（SF）关系必须原样保留并标记为“不支持”，不得静默转换、删除或参与自动排期。
_Avoid_: 负责人资源顺序、任务层级

**依赖时差**：
FS 紧前关系完成后的非负等待时间，以 0.5 天为最小粒度并按当前项目日历换算。负时差不在本期范围。
_Avoid_: 任务工期、日期偏差

**分支批量改派**：
将一个父任务分支中的全部后代任务一次性改为同一负责人或未分配的任务字段编辑。
_Avoid_: 直接编辑父级汇总、逐条改派

**项目成员身份**：
一个系统账号在一个项目中的唯一成员身份，同时展示该账号当前拥有的全部有效角色。
_Avoid_: 按角色重复添加成员、项目内独立角色副本

**项目恢复保护快照**：
项目级恢复覆盖前保存的该项目当前全部业务数据和上传文档，用于将该项目回滚到恢复前状态。
_Avoid_: 整库回滚、应用版本回退

**项目恢复批次**：
管理员一次选择的一个或多个完整项目及其共同的恢复结果。
_Avoid_: 逐项目部分成功、多表恢复任务

**系统事件日志**：
记录业务操作、管理操作、系统运行事件和系统错误的可查询、可导出记录集合。
_Avoid_: 鼠标点击记录、页面浏览轨迹、完整请求镜像

## Relationships

- **任务结构操作**和已保存的**任务字段编辑**进入统一的撤销与重做历史
- **排期导入**必须先生成**排期导入预览**，经用户明确确认后才能写入当前项目 WBS
- **排期导入**默认合并更新：唯一匹配任务被更新，未匹配任务被新增，文件中不存在的当前任务保留不变
- **排期导入**只能通过系统任务 ID、外部 UID 或唯一 WBS 编号自动匹配现有任务
- 没有稳定任务标识的同名或相似任务必须在**排期导入预览**中标记为**疑似任务匹配**，由用户选择关联现有任务或新增任务
- **排期导入**中的依赖关系只能在所有**疑似任务匹配**已解决后重建
- **自动排程任务**的导入日期与任务依赖或负责人资源约束冲突时，系统重新计算日期，并在**排期导入预览**中展示原日期、调整后日期和调整原因
- **固定日期任务**的导入日期与任务依赖或负责人资源约束冲突时，系统保留原日期，并在**排期导入预览**中明确标记冲突、影响范围和可选调整方案；只有用户明确应用方案后才能改动日期
- 导入文件没有提供任务排程模式时，任务默认作为**自动排程任务**处理
- **资源冲突**不仅在**排期导入预览**中展示；导入完成后，任务负责人、日期、工期或依赖发生变化时，系统必须重新检测并在 WBS 中持续提示
- **资源冲突**只计算承担实际工作的叶子任务；汇总父任务、零工期里程碑和未分配任务不占用负责人资源
- **负责人并行**默认允许不同负责人的独立叶子任务在相同时间段执行；只有任务负责人集合存在相同系统账号时才需要进入资源容量和冲突判断
- **可执行任务负责人**只能为一名项目成员；父任务可展示多个**父级负责人汇总**，但该汇总只读、不占用资源且不得参与排期计算
- 当前排期模型不处理**个人不可用时间**；自动排程仅依据项目工作日历和法定节假日计算可工作日期
- **父级日期边界**内的自动排程子任务应优先满足紧前关系、工期和负责人资源约束；无法满足时不得静默延长父任务，而应提示不可行、负浮动及受影响任务
- 子任务日期、工期、依赖或资源约束越过**父级日期边界**时，系统必须形成**硬边界冲突**，列出超出范围、受影响紧前和紧后任务、负责人容量、关键路径及项目结项时间影响，并持续更新可选调整方案；用户可以保留未发布草稿，但未解决前不得发布或变更发布基线
- 未锁定日期的父任务计划开始和计划完成分别汇总为后代任务的最早开始和最晚完成
- **任务依赖类型**本期仅支持 FS；历史或导入的 SS、FF、SF 关系必须保留原始值并标记为不支持，禁止静默转换或删除；未标注依赖按 FS 处理
- **依赖时差**仅允许 FS 的非负 0.5 天粒度时差，并按当前项目日历换算，默认值为零
- 同一负责人承担多个没有直接紧前关系的**自动排程任务**时，系统先满足已有依赖，再按原计划开始时间排序；开始时间相同则按 WBS 行顺序排序
- 负责人前一项任务完成后，后一项**自动排程任务**从下一个可用工作时间开始
- 负责人串行顺序属于资源排程约束，不得写入或伪装成任务的紧前关系
- **固定日期任务**不因负责人串行约束移动；与其他任务重叠时保留日期并提示**资源冲突**
- 当前排期模型不处理**任务暂停**、恢复日期或暂停期间的剩余工时重排；相关需求必须在后续独立迭代中定义后再进入自动排程
- 任意层级任务均可设置或取消**里程碑标记**；该标记只显示星标，不得改变任务工期、日期、工时、进度、负责人、层级或依赖关系
- **预计结项时间**在创建项目时由用户填写，并可在项目信息管理中手动修改；日期不得早于项目开始时间
- WBS 排程变化不得自动覆盖**预计结项时间**；WBS 最晚计划完成时间晚于该日期时，系统允许保存，并在预计结项时间字段处持续显示超期提醒
- 任务名称至紧前任务范围内的 WBS 字段均支持**WBS 字段筛选**；文本字段支持搜索和多选，日期、工期、工时和进度支持范围条件，负责人支持多选及未分配
- 不同字段的**WBS 字段筛选**条件按同时满足组合，同一字段的多个选值按满足任一值组合
- **WBS 字段筛选**命中子任务时必须保留其完整父级路径，但不得显示无关兄弟任务
- **WBS 字段筛选**不得改变任务数据、层级或排序；界面必须标识已筛选字段并支持一键清除全部筛选
- 项目、事项、预算、风险、文档、成员、账号、系统数据和系统日志等行列表格统一使用**透明数据表格**；导航、普通卡片、弹窗、图表和甘特时间轴不在此规范范围内
- **透明数据表格**的单元格只读时完全透明，进入编辑状态后显示焦点边界，点击空白处或按 Enter 均保存并恢复透明状态
- **透明数据表格**的下拉字段必须单击一次展开，并保留各领域必要的层级缩进、状态颜色、警告标识和进度展示
- WBS 任务进度达到 100% 时仅对任务名称显示删除线；任务 ID、星标、层级控件及其他字段保持正常显示
- **Windows 智能服务管理**分别管理 Ollama 和 RAGLite，提供 BAT 入口执行启动、停止、重启和状态查看，用户无需手动执行 PowerShell 命令
- Ollama 和 RAGLite 的开机自启可独立选择且默认关闭；服务启动后执行健康检查，异常退出时自动恢复
- 智能助手设置只展示 Ollama 和 RAGLite 的连接状态及故障提示，不直接获取 Windows 主机进程管理权限
- Windows 完整部署包提供可选的**RAGLite 本地运行环境**；未选择安装时不得创建 RAGLite 守护或自启任务
- **RAGLite 本地运行环境**的知识库数据必须存放在独立持久化目录，PMS 更新、蓝绿切换和回滚均不得覆盖
- 普通 PMS 热更新不携带 RAGLite；只有 RAGLite 版本发生变化时才提供独立升级包
- **Windows 智能服务管理**可以接管部署包安装的 RAGLite，也可以接管用户指定目录中的既有 RAGLite 安装
- **结构化排期文件**使用确定性解析保留层级、日期、工期、负责人和依赖关系
- **半结构化排期文档**由智能助手提取任务并标记字段可信度，不确定字段必须在**排期导入预览**中由用户确认
- 图片和扫描件不属于排期导入支持格式；任何支持格式均不得绕过**排期导入预览**直接写入 WBS
- **排期字段映射**自动识别工作表、表头及常见中英文列名，但允许用户在预览前调整；任务名称是唯一强制要求映射的业务字段
- 未映射的文件字段必须明确列在**排期导入预览**中，不得静默丢弃
- 文件层级优先按父任务 ID 或 UID、WBS 编号、层级数字或缩进依次识别；多种层级表达冲突时必须由用户选择
- 文件内紧前关系优先通过 UID、任务 ID 或 WBS 编号解析；只提供任务名称且存在重名时必须标记待确认
- 用户确认后的**排期字段映射**可以保存为模板并在后续同类文件导入时复用
- 冲突叶子任务在负责人字段旁显示无背景、无边框的红色三角感叹号；悬停内容包含负责人、冲突任务、重叠日期和冲突原因
- 父任务不参与资源占用计算，但后代存在冲突时必须显示**资源冲突提示**并汇总冲突子任务
- WBS 顶部显示资源冲突数量并支持筛选全部冲突任务；点击任务提示可打开明细并跳转到相关任务
- 未分配负责人提示同样只显示无背景、无边框的三角感叹号，并保持在任务拖拽控件和父任务展开控件之间
- 助手生成**排期导入预览**不要求 WBS 写权限，但确认执行**排期导入**必须通过当前账号的项目 WBS 导入或编辑权限校验
- 智能模型不得直接操作数据库；**排期导入**必须调用与人工导入相同的服务端校验和写入边界
- **排期导入**审计记录必须包含操作者、项目、源文件、映射模板、确认时间、新增及更新数量、冲突数量和执行结果
- 排期源文件按项目文档安全规则保存；撤销导入不得删除源文件或审计记录
- 新建任务和未提供**排程模式**的导入任务默认为自动排程；升级前已经存在的任务迁移为固定日期，禁止升级过程静默重算既有排期
- 用户可以单个或批量切换**排程模式**；切换为自动排程前必须预览日期变化并经用户确认
- **排程模式**可通过列菜单显示并通过任务右击菜单切换，默认不占用 WBS 主表宽度
- 固定日期任务仍参与依赖和资源冲突检测；系统默认保留其计划日期，并提供冲突影响和调整方案，只有用户明确应用方案后才能移动日期
- 用户手动修改自动排程任务的计划开始或计划完成日期时，任务默认切换为固定日期；后续排程不得覆盖该用户输入
- 固定日期保存前必须列出本次改期的影响，包括紧前与紧后任务冲突、父级日期边界、负责人容量、关键路径或资源关键链变化及项目预计结项时间偏差；若形成**硬边界冲突**，必须持续提供强提醒和更新后的调整方案，直至冲突消除
- 负责人、工期、计划开始、工作日历、紧前任务或**排程模式**变化后，系统立即计算自动排程影响范围
- 自动排程只影响当前任务时直接保存；会移动其他任务、改变**关键路径**或**资源关键链**、或影响项目**预计结项时间**时，必须先展示修改前后对比和受影响任务清单，经用户确认后再写入
- 引发重排的字段修改及全部联动日期变化共同构成一步任务撤销或重做操作；用户取消重排预览时原字段修改也不得保存
- 进度、实际日期、任务名称和描述等不影响计划排程的字段沿用直接保存行为
- **排期导入预览**必须区分阻断错误和允许确认的警告；存在阻断错误时禁用确认导入
- 任务名称缺失、稳定标识重复、日期或工期无效、层级断裂或循环、依赖自循环或成环、依赖引用无法确认、疑似任务匹配未解决均属于阻断错误
- **资源冲突**、WBS 晚于预计结项时间、文件字段未映射和负责人未匹配属于允许确认的警告
- 文件负责人未匹配项目成员时不得写入无效名称；用户必须映射现有成员或明确选择未分配
- **排期导入预览**必须汇总错误和警告数量并支持跳转到对应任务
- 助手聊天只展示文件解析状态、拟新增更新保留数量及错误警告摘要，通过入口打开**排期导入工作区**
- **排期导入工作区**使用树形表格区分新增、更新、保留、冲突和阻断错误，并允许用户调整映射及预览字段但不得修改源文件
- 所有阻断问题解决后只能在**排期导入工作区**最终确认；导入完成后聊天提供查看 WBS 和撤销本次导入入口
- **资源冲突**按负责人系统账号跨全部未作废项目检测；同名但账号不同的人员不得视为同一资源
- 当前项目排程将其他项目任务视为已占用时间，但不得自动修改其他项目任务
- 用户有对方项目查看权限时，跨项目**资源冲突提示**展示项目、任务及重叠日期；无查看权限时只展示与其他项目任务冲突及重叠日期
- 升级时已有**预计结项时间**晚于或等于项目开始时间的保留原值；早于项目开始时间的同样保留历史值，但在字段处标记必须人工确认
- 已有无效**预计结项时间**不得根据维修周期或 WBS 自动重算；用户保存合法日期后移除提醒
- 新建项目必须由用户填写不早于项目开始时间的**预计结项时间**，不得留空
- 进度达到 100% 的任务冻结计划和实际日期，不参与自动移动
- 进度大于 0% 且小于 100% 的任务固定实际开始及当前计划完成日期，占用负责人至计划完成日期；计划完成已过时提示逾期，不按进度百分比推测剩余工期
- 尚未开始的自动排程任务可以根据依赖和负责人占用重新安排；同一负责人多个进行中任务重叠时只提示**资源冲突**
- 后续未开始任务从进行中任务计划完成日期之后安排
- 系统必须为**资源冲突**生成可解释的**资源排期建议**；任何建议都必须先预览并由用户选择，不得自动覆盖正式排期
- **资源排期建议**提供多个候选方案；用户选择候选方案后直接应用其全部排程变化，并将整套变化作为一步可撤销或重做操作
- **资源平滑**只能使用任务浮动，不得延长项目最晚完成日期；作为资源优化的默认候选方向
- **资源平衡**可以延长项目最晚完成日期，但必须与影响任务、延期天数和残留冲突一并预览，经用户确认后才能应用
- 无依赖、非关键路径的最末级可执行任务的**用户优先级**默认中；同一负责人发生资源竞争时，自动排程按硬约束、关键路径、**生效优先级**、最晚完成约束、原计划开始时间和 WBS 行顺序依次决策
- 对同一负责人、彼此没有依赖且都已满足开始条件的最末级任务，较高**生效优先级**必须先完成；正排或倒排只决定日期从哪一侧计算，不得颠倒该执行先后。依赖关系、固定日期和硬边界始终优先于优先级
- **基线变更草案权限**必须作为权限树中的独立项目权限配置；具备该权限的成员可以准备草案，但只有当前项目经理可以发布基线或应用基线变更
- WBS 基线首次发布和每次变更发布均必须生成不可变的完整**WBS 基线版本**；发布人、发布时间、变更原因、前后差异与通知结果必须可审计
- **基线回退**必须从历史版本创建新的变更草案，经影响预览和项目经理确认后发布为新的版本，历史版本不得被删除或覆盖
- 每个项目必须遵循**单一活动基线草案**；草案发布或作废后才能创建下一份，实际执行数据仍可独立并行填报
- 每次基线发布、变更发布或回退发布均必须创建**基线发布通知**；发布动作不等待成员确认，但通知阅读状态必须可追溯
- 依赖成环、日期格式无效、未来实际完成日期或绕过完成任务重开流程的修改属于数据完整性错误，必须阻止保存和发布
- **排期硬冲突**可以保留在未发布草稿中，但必须持续显示强提醒和动态调整方案，未消除前禁止发布任何基线版本
- **业务风险警告**可以在项目经理填写确认原因后随基线发布；确认原因、风险项和发布时的影响范围必须进入审计记录
- 自动排期遵循**连续任务排期**，只移动整项未完成叶子任务，不得把单项任务拆分成不连续的时间片
- 工期为 0.5 天时必须按**半日排期时段**计算；甘特图、日期悬停信息和日期编辑控件必须明确展示上半日或下半日
- 最末级任务的预计工时必须遵循**预计工时公式**；实际工时可编辑到两位小数，但不得反向覆盖工期或计划日期
- 半日工期以占用时段计算：计划开始和计划完成均是被占用时段，1 天等于 2 个连续半日；FS 紧后任务必须从紧前任务完成后的下一个可用半日时段开始
- 自然日与工作日排期切换必须在 WBS 工具栏持续可见、样式醒目，并明确标识当前选中的项目日历模式
- 项目必须使用统一的**项目日历模式**；变更日历模式必须生成全项目排期、浮动与关键路径预览，基线发布后只能通过基线变更草案修改
- 工作日模式必须使用按年度版本化的中国法定节假日和调休日历，并允许有权限管理员维护**项目日历例外**；日历版本必须写入项目和每个基线版本，升级后的新日历不得静默重算已发布基线
- 默认自动排期只处理**受影响排期集合**，并必须先预览后应用；全项目优化排期只能由用户单独发起，始终先预览再应用
- 自动排程任务必须按**自动排期锚点**选择日期来源：有父级完整边界时在窗口内安排；只有开始边界时正排、只有完成边界时倒排；无父级边界时依次使用项目预计结项时间和项目开始日期；无锚点时保持未排期并强提醒
- 项目预计结项时间是软目标，可用于自动排期锚点和风险提醒；启用**项目硬完成边界**后才作为根层级硬约束，未满足时禁止发布基线
- **无依赖自动任务**在录入工期后不得保持未排期状态；系统必须自动计算计划开始、计划完成、最早开始、最早完成、最晚开始、最晚完成及浮动
- **无依赖自动任务**优先从父级日期边界的完成日期倒排；父级不存在完成边界时，以项目**预计结项时间**作为软目标倒排；两者均不存在时从项目开始日期正排
- 自动排程可以突破项目**预计结项时间**，但必须保留该目标值并提示超期，不得自动覆盖或延后项目目标
- 同一**可执行任务负责人**在同一工作日可承担多个任务，但累计预计工时不得超过其**负责人日容量** 7.5 小时；工期以 0.5 天为最小排程粒度，等价于 3.75 小时
- 固定日期任务超过**负责人日容量**时保留计划日期并提示资源过载；自动排程任务应移至后续可用时段
- 关键路径计算不使用当前进度百分比；未完成任务使用计划时间，已完成任务使用实际完成日期参与时间网络计算。实际完成日期晚于计划完成日期时，必须重新计算关键路径、浮动和受影响的后续任务
- 任务进入**完成任务状态**后不再占用负责人资源；其原有紧前关系不得因完成而丢失，依赖约束的“已满足/活动”状态必须可追溯区分
- 已完成任务与后续任务之间的原依赖关系保留在网络图和审计记录中，并标记为“已满足”；后续任务的当前排期仍以实际完成日期作为可开始时间依据，不得因关系已满足而删除历史边
- 本期新建和编辑紧前关系仅允许**FS 紧前关系**；一项任务可有多个紧前任务，必须在全部关系满足后排期。依赖成环、自身依赖和父子后代反向依赖均属于数据完整性错误
- 历史数据或导入文件中的非 FS 依赖关系必须原样保留并标记为当前版本不支持；不得静默转换、删除或按 FS 猜测计算。含该关系的任务禁止自动排期和发布基线，直至用户明确改为 FS 或移除关系
- 实际开始和实际完成使用**半日排期时段**；实际开始默认上半日、实际完成默认下半日，用户可以调整；任何实际日期均不得晚于当前日期
- **完成任务重开**只能由项目经理通过基线变更完成；重开必须清除实际完成日期、恢复可编辑状态，并重新纳入资源和关键路径计算
- 切换**任务计划计算方式**时，正排保留计划开始和当前工期，倒排保留计划完成和当前工期，日期固定保留计划开始和计划完成；缺少所需输入时保持空编辑状态，不得写入默认日期或工期
- 当前任务因计算方式切换而影响依赖、父级边界、资源或关键路径时，必须先展示影响预览；未经确认不得移动其他任务
- 具有子任务的父任务进度必须按子任务汇总，父任务自身不得直接覆盖该值；父任务实际工时不得与子任务实际工时重复计入
- 父任务汇总进度按**父任务进度权重**计算；临时换算值只用于计算，不得写入预计工时字段
- **排程资源范围**本期仅包含项目成员；数据模型应允许后续新增设备、工装、场地和供应商资源，但不得在本期自动排程中伪造其可用性或冲突
- **关键路径**必须独立于资源占用计算，并在 WBS 表格、甘特时间轴和网络图中提供可视化定位能力
- **资源关键链**必须独立标识，供资源优化、延期风险分析和排期建议使用，不得写入任务紧前关系
- **关键路径**在甘特时间轴中以红色实线任务关系连续展示；**资源关键链**以蓝色实线任务关系连续展示。WBS 表格只显示窄色标记与对应标签，避免干扰常规字段阅读
- 甘特图中的虚线仅用于表示任务浮动时间，不得表示资源关键链或业务紧前关系
- WBS 工具栏必须提供**关键路径**显示/隐藏、筛选及上一项/下一项跳转，并提供资源关键链显示/隐藏；两种链路均使用实线和不同颜色可视化
- 同一任务或关系同时属于**关键路径**和**资源关键链**时，红色实线与蓝色实线必须以固定偏移并列显示，不得混色或相互覆盖；悬停说明分别列出依赖原因和资源等待原因
- **资源排期建议**至少生成三类候选：最小化日期移动任务数及移动天数的最少改动方案、最小化项目总工期的最早完成方案、优先避免超过预计结项时间并保护关键路径及较早截止任务的按期优先方案
- 可直接应用的候选方案只调整尚未开始的自动排程任务，不自动更换负责人，并必须满足依赖、工作日历、资源不重叠和不可移动任务等硬约束
- 冲突完全由固定日期或进行中任务造成时，不生成虚假的可应用方案，只建议人工调整负责人、切换排程模式或改期
- **资源冲突**随任务变化即时检测；三类**资源排期建议**只在用户点击优化排期后基于当前任务快照按需计算
- 候选方案必须展示完成日期、延期天数、移动任务数、总移动天数及仍无法解决的冲突
- 候选生成后负责人、工期、日期或依赖发生变化时立即失效，必须重新计算后才能应用
- 只有用户明确选择全量替换并再次确认时，**排期导入**才能删除当前 WBS 中未出现在上传排期的任务
- 一次**排期导入**整体进入一步**任务操作历史**，其任务、层级和依赖变化必须整体撤销或重做
- **任务插入**属于**任务结构操作**，其数量和位置在执行前确定
- **任务层级调整**携带所选任务的全部后代，但不改变分支内部或分支之间的行顺序
- 复制只处理**显式选择**，剪切、删除和**任务层级调整**同时处理对应的**联动选择**
- **任务剪贴板**中的复制内容可重复粘贴，剪切内容在成功粘贴后清空
- **任务剪贴板**复制任务业务字段和所选范围内的相对关系，但不复制数据库身份或外部对象对原任务的反向关联
- **任务序号**随结构操作实时重算，但折叠任务分支不会改变序号
- **任务序号**是任务行**显式选择**的唯一入口
- 项目事项和风险登记册的序号列是**表格行选择**的唯一入口
- 右击未选中行时，当前**表格行选择**替换为该行；右击已选中行时，保留现有选择集合
- 项目预算不跨预算分类进行批量选择
- **任务操作历史**在当前标签页刷新后保留，在关闭标签页、关闭浏览器或退出登录后失效
- 文件导入、智能助手批量操作和自动排期联动按一次用户动作共同进入一步**任务操作历史**
- 项目 WBS、项目预算、项目事项和风险登记册各自维护独立的**模块操作历史**
- 项目预算的**模块操作历史**同时覆盖预算分类和分类下的预算条目
- 各**模块操作历史**在同一操作会话内最多保留最近五十步，撤销后的新操作会丢弃已撤销分支
- 一次用户动作只进入一步**模块操作历史**；批量删除、批量修改和一次排序在撤销与重做时整体执行
- 删除项目事项或预算条目前，必须展示其**删除影响**，并说明相关数据将自动变为不关联状态
- 撤销删除时，同时恢复删除前记录的**删除影响**中的原关联
- **项目级恢复**必须同时处理项目信息、项目成员、WBS、事项、风险、预算及它们之间的全部项目内关联
- **项目级恢复**不修改其他项目、系统账号、角色、权限和系统设置
- **项目级恢复**只能用备份中的原项目覆盖当前系统中具有同一不可变项目身份的项目；当前系统不存在该项目时，将其作为新项目恢复
- **项目级恢复**不允许把备份项目映射或强制覆盖到另一个现有项目
- **项目级恢复**将项目数据库记录与该项目的全部上传文档视为一个不可分割的恢复单元
- 恢复来源缺少项目文档包或预览检出文档文件缺失时，默认不允许执行**项目级恢复**
- 备份项目引用当前系统已不存在的成员账号时，管理员必须在映射现有账号、设为未分配和执行**关联账号恢复**之间主动选择
- **关联账号恢复**只恢复账号身份和历史项目关联；恢复后账号默认禁用，必须由管理员确认当前角色并设置新密码后才能启用
- **关联账号恢复**不恢复备份中的旧密码和旧权限
- 执行**关联账号恢复**时，恢复预览、恢复结果和账号管理都必须告知操作管理员该账号尚未启用，以及需要完成的角色和密码处理
- **恢复会话延续**要求恢复后的账号与当前账号具有同一不可变身份，处于启用状态且仍具管理员权限
- 不满足**恢复会话延续**条件时，必须结束旧登录状态并要求重新登录
- 没有任何已分配后代的父任务可以选择负责人；该操作向全部后代传播后，父任务转为**父级负责人汇总**
- 只要任意后代已分配负责人，父任务的**父级负责人汇总**必须只读，且只能因后代负责人变化而被动变化
- 需要整体修改已分配分支时，使用**分支批量改派**，不直接编辑**父级负责人汇总**
- 旧版数据升级时，已有父任务负责人只向尚未分配的后代传播，不覆盖已有后代负责人
- 旧版数据中多层父任务均有负责人时，未分配后代优先继承距离最近的父级负责人
- 旧版负责人传播完成后，所有父任务重新计算为**父级负责人汇总**
- 同一系统账号在同一项目中只能存在一个**项目成员身份**
- **项目成员身份**的角色集合来自该账号在后台账号管理中当前拥有的全部有效角色，账号角色变化时同步更新
- 项目内不单独新增或删除**项目成员身份**中的某个角色
- 执行**项目级恢复**前必须创建**项目恢复保护快照**，恢复后可以只回滚该项目而不影响其他项目和系统数据
- **项目恢复保护快照**保留三十天
- **项目恢复批次**允许包含一个或多个**项目级恢复**，但必须作为整体全部成功或全部不执行
- 任意待恢复项目存在未解决的账号映射、文档缺失或数据冲突时，整个**项目恢复批次**不得执行
- **系统事件日志**包含业务增删改、导入导出、撤销重做、负责人和关联变化、登录、账号角色权限、备份恢复回滚、系统启动、定时任务、外部服务连接和异常错误
- **系统事件日志**不记录普通页面查看、鼠标点击、输入过程、密码、令牌、密钥、完整文档内容或未脱敏请求数据
- **系统事件日志**固定保留一百八十天，不提供保留周期配置
- **系统事件日志**最多占用 5GB 存储空间；达到上限时先清理最早的普通信息日志，错误和安全审计日志最后清理
- 日志清理操作本身必须记录为**系统事件日志**
- **系统事件日志**按管理员选择的开始时间和结束时间导出，并支持按日志级别、模块、项目、操作人和关键词筛选
- **系统事件日志**导出结果为 ZIP，同时包含便于人工查看的 Excel、便于技术分析的 JSONL 和记录导出范围与操作人的说明文件

## Example dialogue

> **Dev:** “修改任务名称后，是否应通过结构撤销按钮恢复？”
> **Domain expert:** “需要；已保存的**任务字段编辑**和改变任务集合、层级或排列关系的**任务结构操作**都进入统一历史。”

## Flagged ambiguities

- “撤销任务修改”曾只表示撤销删除；现统一为撤销最近的**任务结构操作**或已保存的**任务字段编辑**。
- “反撤销”和“取消撤销”统一使用术语**重做**。
- “同名任务”不表示已匹配；没有稳定任务标识时统一视为**疑似任务匹配**。
- “里程碑”在本系统中表示**里程碑标记**，不是零工期任务，也不限制为叶子任务。

## Database compatibility

- 业务关联必须使用不可变的数据库主键，不得使用名称、编号等可编辑字段作为关联键。
- 每次数据库结构变更必须同时更新 `prisma/schema.prisma` 和 `prisma/manual-migrations` 中可重复执行的增量 SQL。
- 新增表、列、索引和外键必须使用向后兼容的增量方式；删除或重命名结构必须分阶段迁移，不得在一次发布中直接破坏旧数据。
- 数据库恢复必须在单一事务中重建 `public` schema、导入备份并依次执行全部增量迁移；不得对现有 schema 直接执行 `pg_restore --clean`。
- 每次发布前必须用最早仍在支持范围内的真实备份做隔离恢复演练，恢复后的 Prisma 结构对比必须为零差异。
- `pg_dump` 和 `pg_restore` 的主版本不得低于 PostgreSQL 服务端主版本，Windows、飞牛 OS 和本机环境必须执行同一恢复兼容性测试。

## Source synchronization

- GitHub 和 GitLab 只同步源代码、测试、迁移脚本和项目文档。
- Docker 镜像、离线更新包、完整部署包、数据库备份、运行时数据库和本机缓存不得提交到 Git。
- 只有用户明确要求同步某类发布产物时，才可单独评估其存储位置；默认仍不进入源码仓库。
