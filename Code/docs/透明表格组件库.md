# 透明表格组件库

项目中的业务列表统一从 `src/components/ui/table.tsx` 引用表格组件，不再直接书写原生 `table / thead / tbody / tr / td`。

## 组件

- `Table`：透明表格容器，负责横向滚动、圆角和轻边界；可通过 `wrapperClassName` 设置最大高度等容器样式。
- `TableHeader / TableBody / TableRow / TableHead / TableCell`：统一表头、透明行、悬浮反馈、字号和间距。
- `TableToolbar`：列表筛选、统计和批量操作的工具栏容器。
- `TableActionButton`：表格内文字操作，无正方形边框，适用于下载、回滚、取消新增等动作。
- `TableIconButton`：表格内纯图标操作，无背景边框，适用于筛选、警告、展开等动作。
- `TableEmptyState`：统一空数据行。

## 使用示例

```tsx
<Table className="min-w-[900px]">
  <TableHeader>
    <TableRow>
      <TableHead>名称</TableHead>
      <TableHead className="text-right">操作</TableHead>
    </TableRow>
  </TableHeader>
  <TableBody>
    {rows.map((row) => (
      <TableRow key={row.id}>
        <TableCell>{row.name}</TableCell>
        <TableCell className="text-right">
          <TableActionButton onClick={() => download(row)}>下载</TableActionButton>
        </TableCell>
      </TableRow>
    ))}
    {rows.length === 0 && <TableEmptyState colSpan={2} />}
  </TableBody>
</Table>
```

## 约束

- 行内输入框、下拉框和文本框使用透明变体，不为每个单元格再绘制独立边框。
- 表格内部动作使用 `TableActionButton` 或 `TableIconButton`；弹窗确认、页面主操作仍使用普通 `Button`。
- 筛选和警告图标只显示图标本身，通过颜色、提示气泡和可访问名称表达状态，不显示正方形边框。
- 新增业务列表前先复用本组件库；只有 WBS 这类虚拟化复合网格无法使用原生表格语义时，才可使用专用网格组件。
