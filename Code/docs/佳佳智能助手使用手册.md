# 佳佳智能助手使用手册

## 1. 使用边界

佳佳只能读取当前登录账号有权访问的项目数据，并且只能调用系统已启用的白名单工具。佳佳不会绕过账号角色、项目成员范围、只读项目状态或模块权限，也不会把历史对话中的名称、金额、日期、任务、事项、风险和文档当成实时事实。

当用户询问“怎么操作”时，佳佳应优先依据本手册回答。手册未列出的操作不能描述为已经支持，更不能承诺稍后替用户执行。无法执行时，应明确说明当前不支持，并给出系统内确实存在的入口。

## 2. Agent 授权模式

- 请求批准：佳佳生成操作预览，用户点击“确认执行”后才执行。
- 替我审批：低风险和常规修改操作自动执行；高风险操作仍要求用户确认。
- 完全访问：佳佳可自动执行所有已启用工具，但仍受登录账号的模块权限、项目范围和只读状态限制。

授权模式只改变“何时确认”，不会增加账号原本没有的业务权限。用户可在佳佳窗口标题栏的盾牌菜单中随时切换。

## 3. 项目进度管理

### 3.1 新增与编辑

- 点击“新增任务”创建一级任务。
- 将鼠标移到任务行，使用该行的子任务入口创建下级任务。
- 任务名称、任务类别、工期、计划日期、实际日期、预计工时、实际工时、进度和紧前任务可在表格中直接编辑。
- 日期字段支持日历选择和键盘输入；编辑完成后按字段既有保存规则提交。

### 3.2 层级调整

- 点击“选择”，勾选需要调整的任务。
- 点击“层级下移”，所选任务会成为上一条同级任务的子任务。
- 点击“上移层级”，所选任务会成为原父任务的同级任务。
- 选中父任务时，其全部子任务自动联动；层级调整只改变父子关系和任务编号，不改变数据库主键、依赖关系或事项与风险关联。
- 第一条同级任务无法继续下移，一级任务无法继续上移。

### 3.3 排序、折叠与全屏

- 仅从任务 ID 前的拖拽柄开始拖动；同级任务可拖拽排序。
- 每个父任务左侧可单独展开或折叠；“折叠层级”可按层级批量折叠。
- 点击右上角全屏图标进入全屏编辑；全屏中仍可直接编辑、选择、调整层级、拖拽、折叠和缩放时间轴。

### 3.4 导入与导出

- 支持 MPP、Microsoft Project XML 和系统 Excel 模板导入。
- “追加为新任务”保留现有计划并追加文件任务。
- “合并更新”优先使用系统导出 Excel 中的隐藏数据库键增量更新现有任务；没有稳定键的任务按导入分析结果匹配。
- 支持导出 Excel 和 Project XML。MPP 导出依赖 Windows Microsoft Project 转换服务，未配置时不能声称可直接导出 MPP。

## 4. 项目事项管理

- 事项 ID 由系统按当前顺序维护。
- 事项可直接编辑标题、详细内容、负责人、优先级、状态、进度、日期、问题措施和依赖条件。
- 事项关联任务使用数据库主键，任务改名不会造成关联丢失。
- 风险在风险登记册中关联事项后，会在事项中只读展示；点击风险可查看完整信息。

## 5. 风险登记册

- 风险 ID 由系统按顺序维护。
- 可新增、编辑、删除和拖拽排序风险。
- 风险可选关联项目事项，关联使用数据库主键；事项改名后关联仍保留。

## 6. 文档清单管理

- 文档先选择目录，再批量上传。
- 文件可保存到服务器本地目录，也可在管理员配置公司云盘后保存到云盘。
- 文档目录是文件夹层级，文件显示在所属文件夹下。

## 7. 项目预算与挣值分析

- 项目预算管理维护预算分类和条目。
- 挣值分析使用甘特计划时间、实际时间、进度、预计工时、实际工时及预算关联计算 PV、EV、AC、SV、CV、SPI、CPI、EAC、ETC、VAC 和 TCPI。
- 进度指标描述时间与完成比例，成本指标描述金额；二者不能混用。

## 8. 待办中心

- “项目待办”只显示数据库中真实存在且当前用户可见的未完成待办。
- “通知”显示系统备份等运行告警；通知可一键全部已读。
- 佳佳只有在用户明确要求创建待办并按授权模式批准后，才会写入待办数据。

## 9. 佳佳当前可执行工具

- 创建或完成项目待办。
- 更新甘特任务进度。
- 上移或下移甘特任务层级。
- 更新项目事项状态和进度。
- 新增风险或更新风险状态。
- 导出项目数据和计划分析。
- 将上传的 MPP、Microsoft Project XML 或系统 Excel 与当前甘特计划对比，保存差异、冲突、干涉和影响链分析；分析不会修改当前计划。
- 将单个 MPP、Microsoft Project XML 或系统 Excel 转换为系统可导入 Excel；生成文件前会重新校验任务数量，不会直接写入项目进度。
- 合并多个进度计划附件并生成系统可导入 Excel。
- 读取 DOCX、XLSX、CSV、文本型 PDF、TXT 或 Markdown，诊断结构后分段重写；不补造事实，缺失信息保留为待确认问题，并生成可下载修订稿。
- 保存文档修订稿。
- 将明确选择的计划分析结论转为风险或整改待办。

## 10. 多步骤领域 Agent

- 佳佳可以把明确的连续操作组织成最多 6 步的有向无环计划，每一步只能使用管理员启用且当前账号有权限的工具。
- 典型计划是“对比上传计划 -> 导出分析报告 -> 将严重冲突转为风险 -> 生成整改待办”。
- 中风险步骤按授权模式逐步确认；已完成步骤保留检查点，后续确认不会重复执行。
- 缺少附件或参数时，计划进入“待补充”状态。补充信息后从阻塞步骤继续，不重跑已完成步骤。
- 每个成功计划保存逐步验收证据；失败计划保存错误分类、最后失败步骤和恢复建议。

佳佳不能执行白名单之外的操作，不能直接操作浏览器界面代替服务端工具，也不能绕过确认模式、业务权限或项目只读状态。
