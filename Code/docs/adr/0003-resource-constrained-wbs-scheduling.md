# WBS 排程区分业务依赖与负责人资源约束

任务紧前关系只表达业务依赖，负责人串行执行作为独立资源约束参与排程，不写回紧前任务字段。自动排程只移动尚未开始的自动任务；固定日期、进行中和已完成任务保持日期，并在无法满足资源约束时产生冲突。资源冲突按系统账号跨未作废项目检测，同时遵守项目查看权限。

系统按需生成最少改动、最早完成和按期优先三类候选方案。候选方案必须满足依赖、工作日历、固定任务和人员不重叠等硬约束，展示改动量、完成日期、延期及残留冲突。用户选择后直接应用，整套变化作为一步撤销或重做操作；任务快照变化会使未应用候选失效。

## Consequences

任务需要显式排程模式；升级前已有任务按固定日期迁移，新建及无模式导入任务默认自动排程。叶子任务可关联多名负责人并同时占用这些人员，父任务负责人只由后代汇总。里程碑只是任意层级任务的星标，不改变工期、日期、进度、工时、负责人或依赖。
