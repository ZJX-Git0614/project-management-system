# 系统事件日志固定保留一百八十天

系统数据管理统一汇总业务操作、管理审计、系统运行和异常错误事件。日志固定保留一百八十天，不提供可配置的保留周期；本地存储上限为 5GB，超限后依次清理最早的 INFO、WARN 和 ERROR，SECURITY 日志最后清理。不记录页面浏览、点击、输入过程、密码、令牌、密钥、完整文档内容或未脱敏请求数据。

## Consequences

管理员可按时间、级别、类别、模块、项目、操作人和关键词查询。导出结果为 ZIP，同时包含面向人工审查的 Excel、面向技术分析的 JSONL 以及记录导出条件和操作人的说明文件。日志清理本身也作为系统事件记录。
