# 局部备份恢复以完整项目为最小单位

系统不支持按数据库表或项目内子模块任意覆盖，因为 WBS、成员、事项、风险、预算和上传文档存在强关联。局部恢复以完整项目为最小单位，只能覆盖具有同一不可变身份的原项目；多项目恢复作为一个全成功或全不执行的批次。每次覆盖前保存三十天项目保护快照，以支持只回滚受影响项目，避免整库回滚伤及其他项目。

## Consequences

恢复来源必须同时包含数据库和项目文档；恢复前必须预览账号映射、文档缺失和关联冲突。当备份引用当前已不存在的成员账号时，管理员可映射现有账号、设为未分配，或选择恢复历史账号；历史账号默认禁用，不恢复旧密码和旧权限。
