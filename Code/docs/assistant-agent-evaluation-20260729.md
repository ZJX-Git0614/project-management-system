# 佳佳 Agent 小模型评测（2026-07-29）

## 环境

- 接口：本机 Ollama 原生 `/api/chat`
- 推理模式：`think=false`，`temperature=0`
- 模型：`qwen3.5:4b`（Q4_K_M）、`qwen3.5:9b`（Q4_K_M）
- 数据集：24 条中文项目管理指令
- 命令：`npm run eval:assistant-agent`

## 结果

| 模型 | 动作选择准确率 | 参数线索准确率 | 可执行计划率 | 白名单违规 | 目标通过 |
| --- | ---: | ---: | ---: | ---: | --- |
| qwen3.5:4b | 100.0% | 81.0% | 100.0% | 0 | 是 |
| qwen3.5:9b | 95.8% | 85.7% | 95.2% | 0 | 是 |

目标为动作选择准确率不低于 95%，且白名单违规数为 0。两个模型均通过动作选择目标。

参数线索分数说明小模型仍可能省略或改写用户提供的编号、数值和关键词。生产执行继续采用“确定性规则优先 -> 模型语义归一化 -> 白名单工具 -> 输入 schema 校验 -> 服务端重新定位真实数据”的链路，不允许把模型输出直接作为数据库写入参数。
