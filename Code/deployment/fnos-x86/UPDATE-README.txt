Ceastar PMS 飞牛 OS（fnOS）离线更新说明
======================================

适用范围
--------
1. 仅适用于 x86_64/amd64 飞牛 OS Docker 部署。
2. 更新包是累积应用更新，不需要依次安装中间版本。
3. 更新包不包含数据库备份、项目文档、备份、.env、模型或密钥；特定版本可包含带执行标记的一次性数据更新 SQL。
4. 更新不会替换 PostgreSQL 容器，也不会删除数据库卷和文档卷。

更新步骤
--------
1. 将完整 ZIP 上传到飞牛 OS 并解压，不要只复制镜像 tar 文件。
2. 把解压后的更新包目录放到 Ceastar PMS 原部署目录内。
3. 通过 SSH 进入更新包目录。
4. 执行：
   chmod +x update.sh rollback-update.sh
   ./update.sh

如果更新包不在原部署目录内，可显式指定：
   ./update.sh "/实际路径/Ceastar-PMS原部署目录"

更新过程
--------
1. 校验更新镜像 SHA-256 和 amd64 架构。
2. 调用原部署目录中的 backup.sh，完整备份 PostgreSQL 和项目文档。
3. 加载新应用镜像。
4. 如果包内存在 database/update.sql，校验后短暂停止 pms，事务执行一次性数据更新；重复运行会自动跳过已记录的更新。
5. 仅重建 pms 应用容器；postgres 容器和数据卷保持不变。
6. 等待登录页健康检查通过。
7. 如果健康检查失败，自动恢复旧应用镜像。

手动回滚
--------
更新后需要恢复旧应用镜像时，在同一更新包目录执行：
   ./rollback-update.sh

回滚脚本只恢复应用镜像，不回退数据库和项目文档。需要恢复数据时，使用原部署目录中的 restore.sh 和更新前自动生成的备份。

安全说明
--------
1. 不要执行 docker compose down -v。
2. 不要删除原部署目录中的 .env、backups 目录或 Docker 命名卷。
3. 更新包校验失败时应重新完整复制 ZIP，不要跳过校验。
